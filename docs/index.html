ClearBudget is a free, private, local-first desktop budget planner for Windows, macOS and Linux. It leads with a Safe to Spend Today figure: the most you could spend today while every month that still stands on its own keeps standing, named with the day that constrains it, followed by what you could spend from each later day of the month as income lands. It models forward solvency for the next two months, detects mid-month overdrafts when bills cluster before income, recommends measured changes when a month ahead cannot hold (retiming what can move, then pricing the extra income each month still needs, with try-it-on previews and an optional emergency buffer), tracks credit card utilisation and interest with a six-month balance projection and supports multiple users with bcrypt sign-in and isolated per-user databases, each holding any number of named budgets. A Graph view plots the month as the bank balance day by day or every card on one chart; a month exports as a self-contained web page and a range of months exports as a self-contained folder with an index. It has light and dark themes and a full keyboard path through every screen and dialog. Built with Python and PySide6, it runs offline with no cloud dependency (its only network request is a daily check of the project's GitHub releases for a newer version) and is open source under the LGPL-3.0 licence.
